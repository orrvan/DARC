# 战斗与 PvP（Combat & PvP）· 异步 3v3

# 长老竞技场（The Elder Arena）

Zenko 的 PvP 是一个**异步 3v3 天梯**。你只需设定一次三只生物的**防守队伍**；每当另一位训练师挑战它时，它会自行战斗，而你花费门票去进攻别人的队伍。没有人需要同时在线——每场战斗都是一个**确定性模拟**：服务器从一个种子权威地运行它，客户端只是回放日志，所以相同的队伍和种子总是产生相同的战斗。

战斗是一个 **CTB（条件回合战斗，Conditional-Turn-Battle）**，属于 FFX / FF7 血统：出手顺序由**敏捷（Agility）**驱动，每只生物缓慢地为其单一**招牌技能**蓄力，一旦充能条达到 100% 便自动释放。

**三条硬规则**

1. 只有**长老阶段（Elder）**的生物才能进入 PvP——Baby / Juvenile / Adult 无法战斗。
2. 一支队伍恰好为 **3 只生物**：一只**前排**（坦克 / 承伤）和两只**后排**。
3. 排位进攻需要花费**门票（tickets）**——你每天获得 **10 张**，大约每 **2.4 小时**再生一张。

奖励纯粹是荣誉和宝石——**PvP 永不产出任何 $ZOLANA**。每周结算向前 10 名支付固定的 **200 宝石**分配，并加冕一位赛季**冠军（Champion）**。

## 一场战斗如何决出 · CTB 引擎

### 出手顺序——行动值（Action Value）

每个单位都有一个倒数的**行动值（AV）**；数值归 0 的单位下一个行动，所以更快的生物行动更频繁。平局时偏向更高的敏捷。

```
AV = round( 10000 / effAgility )
普通攻击后 → 充能条重置为 AV × 1.0
技能释放后 → 充能条重置为 AV × skillRank（1.25 – 1.45，即终极技的节奏代价）
```

### 技能蓄力

每只生物的招牌技能带有一个 **0 → 100 的充能**：

- 每次行动 **+25 充能**——所以技能大约每 **4 个回合**释放一次。
- 被**命中**时额外 **+至多 25**（按承受伤害相对最大 HP 缩放）——这是翻盘杠杆，所以处于劣势的队伍蓄力更快。
- 达到 **100** 时技能自动释放、重置为 0，并支付上文的额外节奏代价。

### 伤害与减免

一次命中把基础攻击经过技能倍率、元素轮盘和一条柔和的防御曲线：

```
raw = ATK × powerMult × elementMult × 1.6（dmgScale）
dealt = round( raw × 140 / (140 + effDef) )（最小 1）
```

防御永远不会把一次命中归零——它只是软化命中（常数 **140** 调节坦克能扛下多少），所以战斗总是以击倒而非僵局收场。**Nuke（核弹）**技能还额外无视目标 **25% 的防御**（破防）。

### 战斗结束

- **团灭（Wipe）**——一方被完全击倒。有一回合的*反斩杀宽限*：在每个单位至少行动过一次之前，没有人会死亡。
- **超时（Timeout）**——在 **40 次行动**后战斗结束；剩余平均 HP% 更高的一方获胜。进攻方（挑战者）在平局时**落败**。

## 女巫试炼 · 限时活动

**女巫试炼（Witch Trial）**是一个限时活动 Boss，作为**实时的、世界内**战斗进行——你操控训练师在竞技场中四处走动，躲避她预告的攻击，同时你的 **3 只生物队伍**自动战斗。它运行在与 PvP*相同*的伤害引擎上，附带以下几条活动专属规则，以便你规划队伍并**自己算数**。

### 你对女巫造成的伤害

每次命中使用核心公式——但**元素轮盘对女巫不生效**（她没有对局弱点），所以简化为：

```
dealt = round( ATK × skillMult × 1.6 × 140 / (140 + 120) )（女巫 DEF = 120）
× 方差（0.92 – 1.08，±8%）× 暴击（8% 基础 + Precision 遗物 → ×1.5 + Ferocity）
```

因为女巫 DEF 为 120，你原始伤害的 **≈54%** 会命中（`140 / (140+120)`）。试炼读取你的**真实有效属性**——与 PvP 使用相同的 ATK/DEF/HP/AGI（来自稀有度、阶段、变体、等级、遗物 % 加成和队伍力量 Party Power），并且你的**战斗遗物战斗属性也生效**：**暴击几率**和**暴击伤害**提升你的暴击，**吸血（Lifesteal）**从造成的伤害中为你回血，**护盾（Ward）**让每只生物开局带一个护盾。`skillMult` 普通攻击为 **1.0**，技能则为原型值：

| 行动 | skillMult | 效果 |
|---|---|---|
| 普通攻击 | 1.0× | 每次按 AGI 计时的挥砍 / 射击。 |
| NUKE 技能 | 2.2× | 最大的单次命中。 |
| CONTROL 技能 | 1.4× | 扎实的核弹（对 Boss 无充能拉扯）。 |
| TANK 技能 | — | 为自身护盾 **其最大 HP 的 25%** 而非伤害。 |
| SUPPORT 技能 | — | 为**全队回复最大 HP 的 17%** 而非伤害。 |

#### 计算示例

一只 **ATK 250** 的 Nuke 生物释放其技能：

```
raw = 250 × 2.2 × 1.6 = 880
dealt = round( 880 × 140 / 260 ) = 474 → 暴击 ×1.5 ≈ 711
```

它的普通攻击（skillMult 1.0）每次造成 `round(250 × 1.6 × 140/260)` = **215**。把一次探索中每只生物的普攻 + 技能加起来，就是你累计的伤害。

### 在女巫面前生存

在试炼中，你生物的**战斗 HP 会被 ×6**（战斗持续数分钟，而非 40 次行动的交换——一只健康的生物在倒下前总能吃下 **≥3** 次预告命中）。女巫的伤害是**按最大 HP 百分比削减**（普攻约 10%，技能 ≤35%），所以更大的 HP 池纯粹是生存力；你的**输出伤害不变**。被击倒的生物不会永久死亡——只有你为进入而牺牲的那 3 只长老消失了。

**用数字看这场探索**

屏幕上的女巫每次探索对一支中位数队伍有 **≈30,000 HP**（她会为更强的队伍*向上*缩放，所以每个人都需要相似数量的胜利）。每次探索有 **3 分钟**上限，你的伤害在多次探索间**累计存入**——约 **10 场胜利**填满你的进度条。撤退或超时仍会存入你已造成的伤害。点击女巫随时可见进度和奖励包。

## 技能引擎 · 28 个技能

每只生物恰好拥有**一个**技能，由其**战斗原型 × 元素**自动决定。原型是*行动*（技能做什么）；元素只是*上色*——风味名称、特效颜色和轮盘对局。四原型 × 七元素 = **28 技能目录**。

### 生物的原型如何决定

原型由属性面板（或辅助被动）派生，所以你通过选择生物来选择队伍的定位：

**NUKE 大伤害**——技能伤害 220% ATK · 附带 −25% DEF · 目标最低 HP · 节奏 AV × 1.40

**TANK 承伤与嘲讽**——护盾 25% 最大 HP · 附带嘲讽 1 回合 · 目标前排友方 · 节奏 AV × 1.25

**CONTROL 节奏压制**——技能伤害 120% ATK · 附带充能拉扯 · 目标最低 HP · 节奏 AV × 1.45

**SUPPORT 团队治疗**——治疗（全体）17% 最大 HP · 附带净化 · 目标全体友方 · 节奏 AV × 1.30

- **Support** 优先判定：拥有 *HappinessKeeper*、*Radiance* 或 *Inspiration* 被动的生物始终是辅助。
- 否则由最高属性决定：若 `Defense + HP/5` 最高则为 **Tank**，否则若 Attack > Agility 则为 **Nuke**，否则为 **Control**。

**附带效果详解**

**破防（Def-pierce）**——核弹无视目标 25% 的防御。**护盾 + 嘲讽**——坦克为前排友方施加持续 2 回合的 HP 护盾，并强制敌人攻击它 1 回合（约 50% 嘲讽覆盖率，非永久）。**充能拉扯（Gauge-pull）**——控制把目标的回合推后其 AV 的 30%；*更快的目标能抵抗*它。**净化（Cleanse）**——清除负面状态（为未来的持续效果预留）。

### 完整的 28 技能目录

行是元素，列是四个原型行动。同一行内行动完全相同——只有名称和颜色改变。

| 元素 | NUKE · 220% ATK | TANK · 护盾/嘲讽 | CONTROL · 120% + 拉扯 | SUPPORT · 全体治疗 |
|---|---|---|---|---|
| Terra | Stone Maul | Bulwark Stance | Quagmire | Grove Mend |
| Flora | Thorn Volley | Bramble Wall | Spore Bind | Bloomsong |
| Aqua | Tidal Fang | Coral Guard | Riptide | Tidecall |
| Ignis | Cinder Lance | Ember Aegis | Flare Snare | Warmth Pyre |
| Aero | Gale Cutter | Zephyr Veil | Gale Slip | Tailwind |
| Void | Umbral Rend | Dusk Mantle | Hex Pull | Soul Knit |
| Lux | Radiant Spear | Aegis of Dawn | Prism Lock | Dawnsong |

普通攻击（在充能之间）始终以 100% ATK 命中敌方前排单位，并把充能条重置为 AV × 1.0。

## 元素对局 · ±20%

每次命中都乘以**元素轮盘**。该加成被有意设得温和，使好的对局是一种真正的优势，而非硬性克制：

| 对局 | 伤害 × |
|---|---|
| 攻击方**克制**防御方（优势） | **1.2×**（+20%） |
| 攻击方**受制于**防御方（劣势） | **0.8×**（−20%） |
| 中立 / 轮盘外 | 1.0× |

### 轮盘

五种元素构成一个环；Lux 和 Void 在一个相互对偶中彼此克制：

```
Ignis → Flora → Aqua → Terra → Aero → Ignis（各自克制下一个）
Lux ⇄ Void（相互优势）
```

| 元素 | 克制（1.2× 对） | 受制于（0.8× 来自） |
|---|---|---|
| Ignis | Flora | Aero |
| Flora | Aqua | Ignis |
| Aqua | Terra | Flora |
| Terra | Aero | Aqua |
| Aero | Ignis | Terra |
| Lux | Void | Void |
| Void | Lux | Lux |

Aero 与 Lux/Void 除所示环外没有轮盘内弱点；每种元素既克制一个又被一个克制，所以没有元素是绝对占优的。

## 力量公式 · 匹配锚点

每只生物都有一个**有效力量（Effective Power）**分数。它把基础属性汇入一个数字，并按每一条进程轴缩放。你队伍的总力量决定你被匹配到谁。

### 有效力量（每只生物）

```
base = HP + ATK×3 + DEF×2 + AGI×2（已折入遗物属性% 与固定加值）
Power = round( base × RarityMult × StageMult × VariantMult × LevelMult × (1 + relicPower) )
```

每个乘数都是你可控的真实杠杆：

**等级乘数** 战斗等级是与阶段分离的一条轴。**每级 +4% 力量**，Lv 100 封顶：
```
LevelMult = 1 + (level − 1) × 0.04 → Lv1 = 1.00× · Lv50 = 2.96× · Lv100 = 4.96×
```

**阶段乘数** 只有长老生物战斗，但属性乘数仍以其顶值应用：

| 阶段 | 战斗属性 × | 可战斗？ |
|---|---|---|
| Baby | 0.50× | 否 |
| Juvenile | 0.75× | 否 |
| Adult | 1.00× | 否 |
| Elder | **1.50×** | **是** |

**战斗遗物装备加成** 一只生物装备 **3 件战斗遗物**。它们的逐属性加成*相加*后触及**逐属性上限**，所以装备是一条真实的构筑轴（约占后期力量的 35–45%），但绝不氪金取胜。四项力量属性直接折入有效力量；其余是引擎直接读取的战斗属性：

| 战斗属性 | 在战斗中作用 | 相加上限 |
|---|---|---|
| Attack %（攻击） | 缩放基础攻击（力量属性） | +90% |
| Defense %（防御） | 缩放基础防御（力量属性） | +90% |
| Max HP %（最大生命） | 缩放基础生命（力量属性） | +100% |
| Agility %（敏捷） | 缩放基础敏捷 → 更早行动（力量属性） | +75% |
| Power %（力量） | 对整个力量分数的固定加成 | +60% |
| Crit Chance（暴击几率） | 打出暴击的几率 | +45% |
| Crit Damage（暴击伤害） | 暴击时的额外伤害（基础暴击 = +50%） | +150% |
| Lifesteal（吸血） | 回复你造成伤害的一定百分比 | +45% |
| Ward（护盾） | 开局护盾 = 最大 HP 的百分比 | +75% |
| Luck / Fortune（幸运） | 更多突袭金币与批量材料掉落——经济属性，非战斗（队伍相加的 Fortune 每次突袭封顶 +50%） | +75% |

一次**暴击**造成基础 +50% 外加你滚出的暴击伤害；**吸血**从造成的伤害中回血；**护盾**在战斗开始时成为一个护盾缓冲，吸收开局爆发。完整目录见 [遗物（Relics）](relics.md) 页。

### 队伍力量（天梯数字）

你防守卡上显示的数字*不是*原始总和——它经过一个平方根压缩，使巨鲸队伍无法被匹配到比公平队伍高一千个名次之上：

```
TeamPower = round( 90 × √( Σ 全部 3 只生物的有效力量 ) )
```

## 稀有度与变体战斗乘数 · 属性缩放

力量公式中有两个乘数来自生物的稀有度及其闪光变体。以下是确切的实时数值（镜像自 [生物图鉴（Creatures）](creatures.md)）：

| 稀有度 | 战斗 × |
|---|---|
| COMMON | 1.0× |
| UNCOMMON | 1.2× |
| RARE | 1.5× |
| EPIC | 2.0× |
| LEGENDARY | 2.8× |
| MYTHICAL | 4.0× |

### 变体战斗加成

| 变体 | 战斗 × |
|---|---|
| Normal | 1.00× |
| Shiny | 1.15× |
| Golden | 1.35× |
| Shadow | 1.50× |
| Rainbow | 2.00× |

### 你卡上的数字**就是**你的战斗属性

你的生物卡和检视器显示每只生物的**真实战斗属性**——战斗引擎实际输入的确切 ATK / DEF / HP / AGI——而非原始基础数字。每项属性都是基础值经过与力量完全相同的乘数：

```
shownStat = round( baseStat × RarityMult × StageMult × VariantMult × LevelMult )
```

这就是为什么一只 Mythical 的卡读数远高于其基础值：它在阶段、变体和等级之上还携带 **×4.0** 稀有度乘数（Legendary ×2.8）——所以一只低基础的 Mythical 在竞技场里仍胜过一只高基础的 Legendary。战斗遗物是情境性装备，所以它们的 % 加成通过**有效力量**浮现，而非烘焙进这一逐属性基线。

**属性 + 力量，而非硬性克制**

因为每个乘数都是相乘的，一只 **Lv 100 的 Rainbow Mythical 长老**远比 Common 强大得多——但元素轮盘、原型附带效果和平方根压缩的匹配意味着一支构筑良好的较低稀有度队伍仍有真正的反制空间。PvP 奖励的是*构筑技巧*，而不仅仅是最大的数字。

## 天梯、层级与每周结算 · 赛季制

### 门票与计分

你用**门票**进攻——**每天 10 张**，约每 2.4 小时再生一张（一道反刷取门槛）。每个结果移动两个数字：你隐藏的 **ELO**（匹配）和你可见的**天梯分数**（你的名次）。

- **胜利**——分数按差距缩放：`max(10, 18 + (oppELO − myELO)/20)`。击败排名在你之上的人回报更多。
- **失败**——一个小的 **4 分**安慰，所以尝试永远不会把你打回零。
- **NPC 对手**——预置的机器人队伍使天梯永不为空，但只支付正常胜利分的 **40%**。

### 层级

天梯分数把你分到五个层级，各自带有递增的每周材料宝箱：

| 层级 | 所需分数 |
|---|---|
| Bronze（青铜） | 0 |
| Silver（白银） | 1,000 |
| Gold（黄金） | 2,200 |
| Platinum（铂金） | 3,800 |
| Champion（冠军） | 5,600 |

### 每周结算

每个赛季持续 **7 天**。结算时：

1. 前 10 名分配固定的 **200 宝石**池（分层，而非按比例分成）。
2. 第 1 名被加冕为**冠军**，并获得永久的 *Champion · Season N* 徽章。
3. 每位玩家的分数**软重置**为 `tierFloor + ½ × excess`——赛季会压缩，但你的名次仍会带着分量进入下一赛季。

| 名次 | 宝石奖励 |
|---|---|
| 第 1（冠军） | 60 |
| 第 2 | 40 |
| 第 3 | 25 |
| 第 4 | 18 |
| 第 5 | 14 |
| 第 6 | 11 |
| 第 7 | 10 |
| 第 8 | 8 |
| 第 9 | 7 |
| 第 10 | 7 |

总池 = 60 + 40 + 25 + 18 + 14 + 11 + 10 + 8 + 7 + 7 = **200 宝石**。宝石是稀缺货币——天梯是游戏中为数不多的宝石来源之一。

**冠军**

在位的赛季冠军在城镇各处都无从辨错：他们的生物佩戴**红色战斗光环**和一顶**王冠**，其个人资料卡上名字旁有王冠标记。该头衔（及其赛季徽章）即使在天梯重置后也是永久的。

## 构筑防守队伍 · 策略

因为战斗自动决出，你的**队伍构成与阵型就是全部游戏**。从上述引擎中直接得出的几条原则：

- **把坦克放前排。** 普通攻击和前排目标逻辑首先命中你的前排单位；那里放一个 Tank 原型会为它护盾并嘲讽，为你的后排争取蓄力时间。
- **速度即节奏。** 高敏捷（或一件敏捷遗物）意味着更多回合、更快蓄力，以及对控制充能拉扯的抵抗——最快的队伍滚雪球。
- **覆盖轮盘。** 混合元素意味着通常至少有一只生物拥有 1.2× 优势，且你永远不会被完全克制。
- **核弹收尾，辅助续航。** Nuke 以最低 HP 的敌人为目标以确保击倒；Support 每次施法为全队回血，并在超时时凭 HP% 取胜。
- **给对的属性上装备。** Nuke 上暴击几率 + 暴击伤害，Tank 上护盾 + 最大 HP，肉搏型上吸血——遗物是队伍身份最终定型之处。

**记住**

你的防守队伍在*没有你*的情况下战斗，所以要构筑成能自动取胜。然后花你每天的 10 张门票去进攻力量略高于你的队伍以获得最大的分数摆动，并在每周结算时回来领取你的宝石。
