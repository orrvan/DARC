# 🐾 保姆级教程｜Zenko 新手上路：一小时从零开始养出你的第一只像素神兽

> 一篇给中文区小伙伴的入门长文。Zenko 是 Solana 上一款「养成 + 挂机 + 收集」的休闲像素游戏——孵蛋、养崽、放岛上躺赚金币、进化繁殖、下副本、打 PvP，还能玩家间自由交易。**不用钱包、不用花一分钱就能开玩**，先上手再说。

---

## 🎮 一句话看懂这游戏

买蛋 → 孵化 → 放到岛上 → 躺着赚金币（Gold）→ 拿金币再买蛋 / 进化 / 繁殖 → 下副本、打竞技场、上市场交易 → 循环滚雪球。

整个游戏就是这一个循环，越滚越大。

---

## 🎁 第一步：领新手礼包（0 门槛）

每个新号开局白送：

- 💰 **2,500 金币（Gold）**
- 🥚 **2 枚基础蛋（Basic Egg）**
- 💎 宝石（Gems）：0 —— 之后才慢慢赚

> 划重点：**金币 = 天天刷天天花的日常货币；宝石 = 稀缺高级货币，要省着用。**

---

## ⏱️ 你的第一个小时，照着做就行

**1️⃣ 孵第一只崽**
打开鸟巢（Nest），把基础蛋丢进孵化槽，几分钟就出崽。另一枚留着备用或以后繁殖。

**2️⃣ 放到岛上躺赚**
放置的生物会在你离线时被动产金币。稀有度越高、等级越高，每小时越多。离线收益最多累计 **8 小时**，记得回来收。

**3️⃣ 喂养 + 升级**
喂食涨幸福度 + 经验。战斗等级靠经验**自动升**，不用手动点，还顺带提高躺赚收入。

**4️⃣ 花掉你的 2,500 金币**
前期「广度 > 深度」——多放几只崽比堆一只强，金币来得更快。

**5️⃣ 跑一次副本（Dungeon）**
派队伍进低级副本，消耗体力和一点时间，产出金币 + 材料 + 偶尔遗物。**这是你的金币主水龙头。**

**6️⃣ 进化 / 繁殖 / 战斗 / 交易**
之后就自由发挥，按自己的节奏玩这个循环。

## 💰 三种货币，别搞混

| 货币 | 定位 | 怎么来 | 怎么花 |
|---|---|---|---|
| **Gold 金币** | 充裕·日常 | 副本 + 挂机 | 买蛋、喂养、进化、繁殖、买放置槽 |
| **Gems 宝石** | 稀缺·高级 | 每周免费津贴、Epoch 社区基金、活动 | 高级蛋、装扮、存储升级、遗物重滚 |
| **$ZOLANA** | 链上代币 | 市场 / 交易所 | 市场交易、拍卖行、秒充体力；**持有还能加成收益** |

⚠️ 金币是拿来疯狂周转的，宝石是拿来存的，$ZOLANA 是拿来持有的。

## 🔑 什么时候才需要连钱包？

**整个第一小时——孵蛋、放置、升级、下副本——都不用钱包！**

只有当你想碰链上经济时才连 Solana 钱包（Phantom / Solflare 等）：

- 持有 $ZOLANA（能提升每周宝石收入）
- 在玩家市场用 SOL 买卖道具
- 参加拍卖行 Zothebyz

> 登录只签一次名，**不动一分钱、8 小时内免弹窗**，也永远不会问你助记词。放心玩。

## 📈 进阶要点（想变强就看这些）

**🏰 副本才是金币主来源**
共 25 个副本、5 大区域。越深金币越多、材料越多。别只盯着材料——**三种基础材料每个副本都掉**，深处只是掉得更多 + 宝石率更高。

**🧬 繁殖看「层级」不看「稀有度」**
后代层级 = min(双亲层级) + 1。商店/高级蛋出的崽**不管多稀有都是第 0 层**；神秘蛋（Mystery Egg）的崽自带第 2~4 层。想繁出高层级，双亲都得够高。失败也退 50% 金币，不亏光。

**⚔️ PvP 只有「长老（Elder）」能上场**
异步 3v3 自动战斗，设好防守队它自己打。讲究元素克制（±20%）+ 阵容搭配：前排坦克、后排输出、混元素别被完全克制。每周结算给宝石，第一名有专属冠军光环 👑。

**✨ 变体（Variant）是隐藏彩票**
每只崽孵化时随机滚变体：Shiny / Golden / Shadow / **Rainbow（千分之一，金币 ×15、战力翻倍）**——出彩虹就是赚到。

**🎃 限时活动·女巫试炼**
献祭 3 只长老换一次性入场券，实时躲技能打 Boss，冲榜拿传说级「女巫犬」（每期全服仅 10 只，可交易）。

- 每天领登录奖励（7 天连签共 13.5 万金币）+ 做每日/每周任务。
- 宝石省着买高价值的（高级蛋、槽位扩展），别乱花。
- 达到账户 5 级解锁市场，每周还能免费领 4 宝石起。
